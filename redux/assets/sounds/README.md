# Menu sounds

Original cues made for Redux with ElevenLabs sound effects (text-to-sound), then trimmed, faded and normalised by tools/sounds/make_menu_sounds.py. 16-bit mono 44.1 kHz WAV. move: focus moves; select: A; back: B; open: the System menu opens.

`disc-load.mp3` is the owner's recording of a physical disc tray opening and the disc loading (7.1 s, supplied 2026-11-15). It plays on the loading stage when a CD console's game loads (Sega CD, PlayStation, Saturn, TurboGrafx-CD, Neo Geo CD, 3DO, Jaguar CD), through Windows MCI so it mixes with the menu sounds, and follows the Menu sounds setting.
