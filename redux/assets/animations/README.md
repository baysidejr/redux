# Stage animations

Owner-made pixel-art sprite sheets, one per console, supplied 2026-11-15: 3840x2160 PNG,
8 columns of 480x270 cells, 60 frames each (intro 0-23: the tray or slot takes the game;
loop 24-47: the loading bar; outro 48-59: the bar completes), 12 frames per second,
transparent background. `animations.json` is the manifest the stage reads. No vendor image
pixels are incorporated. See docs/ANIMATIONS.md for the format and how to add one.
