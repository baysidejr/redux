Unknown/multisession/recordable-media completion state, unsupported driver modes, and ambiguous pregap/mode transitions are refused. Thirteen injected-device/Windows-ABI tests pass; no physical capture was invoked. This is not full-disc/subchannel/protection/pregap reconstruction or calibrated secure audio extraction. ## Original-application investigation

The supplied installer and extracted material are local research inputs, not required runtime files. Investigation established:

- Six setup payloads and 254 installer-bundle entries extracted with size/hash checks.
- Native C++ type/vtable structure plus targeted startup, library, dispatch, save-buffer, and input-interface traces.
- SCYGT100 resource structure: **43,383 index entries, 2,816 embedded files, 589,491,882 decoded bytes**, with wrapped size/CRC64 and independent asset checks.
- Catalogue structure: **19,272 records, 14 system keys, 36 fields**, plus original readers for the catalogue/resource pack and typed lookups.
- Observed dispatch to Mesen, Mednafen, Kega, MAME, M64P and a fake/test hook. This reference map is not an implementation or redistribution claim for those cores.
- Shared original hook state-buffer methods and host-owned N64 input callbacks, plus RTTI-validated consumption/shader-menu anchors and controller Home-capability profiles, including the Atari VCS profile.
